# Boss-Bilder: Dateinamen

Fuer jedes Boss-Bild eine Datei **`RAID_boss.png`** (oder `.jpg`) anlegen, z. B. `MC_ragnaros.png`.
Quadratisch ist am besten (mindestens 128x128). Die Dateien kommen in einen Ordner `bossimages/`; ich wandle sie in das
Spielformat (TGA, 128x128) um und baue sie in das Boss-Fenster ein. Bosse ohne Datei behalten das bisherige Symbol.
